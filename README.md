# ربات تبلیغاتی سوینجوب (SevinJob) برای روبیکا

ربات ارسال خودکار محتوای تبلیغاتی (متن + عکس) برای کانال کارگاه/شرکت **سوینجوب** که کارش تولید و فروش عمده و خرده **سرویس خواب** است.

## ویژگی‌ها
- ارسال خودکار متن‌های تبلیغاتی جذاب به کانال
- تولید و ارسال عکس تبلیغاتی با متن، شماره تلفن و آیدی کانال
- قابل تنظیم فاصله زمانی ارسال
- ساختار تمیز و آماده برای قرار دادن توکن، آیدی کانال و شماره تلفن

## نصب

```bash
pip install -r requirements.txt
```

## تنظیمات

فایل `config.py` را باز کنید و مقادیر زیر را پر کنید:

- `BOT_TOKEN` → توکن ربات از @BotFather روبیکا
- `CHANNEL_ID` → آیدی عددی کانال (مثل `b0xxxxxxxxxx`)
- `CHANNEL_USERNAME` → آیدی کانال (مثل `@sevinjob`)
- `PHONE_NUMBER` → شماره تلفن تماس

## اجرا

```bash
python bot.py
```

ربات به صورت دوره‌ای (پیش‌فرض هر ۶ ساعت) یک پست تبلیغاتی (متن + عکس) به کانال ارسال می‌کند.

## ساختار پروژه

```
sevinjob-rubika-bot/
├── bot.py              # کد اصلی ربات
├── config.py           # تنظیمات (توکن، آیدی کانال، شماره)
├── contents.py         # متن‌های تبلیغاتی آماده
├── image_generator.py  # تولید عکس تبلیغاتی با Pillow
├── requirements.txt
└── README.md
```

## نکات مهم
1. ربات باید ادمین کانال باشد و دسترسی ارسال پیام داشته باشد.
2. بعد از پر کردن `config.py` ربات را اجرا کنید.
3. متن‌ها و عکس‌ها را می‌توانید در `contents.py` و `image_generator.py` تغییر دهید.

ساخته شده برای کارگاه سوینجوب 🛏️
