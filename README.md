# ربات تبلیغاتی سوین چوب (خصوصی – اجرا روی GitHub Actions)

ربات ارسال خودکار **۲ پست تبلیغاتی روزانه** به کانال روبیکا `@sevinchoob`.

## زمان‌بندی خودکار
- هر روز ساعت **۱۱:۰۰ صبح** به وقت ایران
- هر روز ساعت **۲۰:۰۰ شب** به وقت ایران

این زمان‌بندی از طریق **GitHub Actions** انجام می‌شود (مثل ربات‌های قبلی شما). نیازی به VPS یا سرور جداگانه نیست.

## محتوا
هر پست شامل:
- عکس تبلیغاتی (شماره تلفن + آیدی کانال + اینستاگرام روی عکس)
- یکی از **۲۰ متن تبلیغاتی متنوع** (تصادفی و کم‌تکرار)
- در انتهای متن: شماره تلفن + آیدی کانال + اینستاگرام + لینک کانال

## نحوه کار
فایل `.github/workflows/daily-promo.yml` هر روز در دو ساعت مشخص اجرا می‌شود و یک پست ارسال می‌کند.

می‌توانید از تب **Actions** در گیت‌هاب، دکمه **Run workflow** را بزنید و دستی هم تست کنید.

## اجرا برای ۶ ماه و بیشتر
زمان‌بندی GitHub Actions تا زمانی که workflow را غیرفعال نکنید ادامه دارد. نیازی به تمدید دستی نیست.

## نکات
- مخزن **خصوصی** است.
- توکن و اطلاعات حساس فقط در این مخزن قابل مشاهده است.
- اگر پست‌ها ارسال نشد، به تب Actions بروید و لاگ‌ها را چک کنید.

ساخته شده برای شرکت سوین چوب 🛏️
