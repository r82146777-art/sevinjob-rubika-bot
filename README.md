# ربات سوین چوب (خصوصی)

## پست خودکار کانال
- فقط **متن تبلیغاتی** (بدون عکس زمان‌بندی‌شده)
- هر روز یک پست صبح و یک پست شب
- متن‌ها بلند، جذاب و غیرتکراری

## افزودن عکس دستی
در چت خصوصی ربات در روبیکا:

1. بنویسید: **افزودن عکس**
2. ربات می‌گوید: لطفاً عکس‌ها را ارسال فرمایید
3. چند عکس بفرستید
4. بنویسید: **ارسال**
5. ربات عکس‌ها را به‌ترتیب با کپشن به کانال می‌فرستد

برای این قابلیت باید ربات را یک‌بار به صورت مداوم اجرا کنید:

```bash
python bot.py --listen
```

(روی یک سیستم روشن یا VPS)

دستورات:
- `افزودن عکس`
- `ارسال`
- `لغو`
- `/start`
